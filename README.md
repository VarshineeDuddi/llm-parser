# Template-Driven Document Parser

This repo is bootstrapped, not built yet. No application code exists.
`openspec/` holds the workflow
schemas that will govern how the application gets designed and
implemented. See `COMMANDS.md` for the exact command sequence.

## What's here

- `openspec/config.yaml` — project context and per-artifact rules, shown
  to the agent on every artifact it drafts.
- `openspec/schemas/` — three workflow schemas:
  - `parser-standard` (default) — discuss → proposal → specs → design →
    security-privacy → test-strategy → tasks
  - `parser-sensitive` — same, plus a `review` artifact that structurally
    blocks `test-strategy`/`tasks` until an architect's PR approval
    produces it
  - `parser-rapid` — discuss → proposal → tasks only, for genuinely
    trivial bounded changes
- `.claude/` — generated by `openspec init`; gives Claude Code the
  `/opsx:*` skills and commands.
